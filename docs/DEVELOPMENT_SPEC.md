# 3D 地球音乐可视化 - 开发规范

## 一、整体视觉哲学

UI要达到的不是"炫"，而是：

**克制的科技感 + 有呼吸的动效 + 有主次的视觉层级**

### 核心关键词

- 主体突出（地球）
- 数据有生命（光柱 / 粒子）
- 动效有节奏（不是乱动）

---

## 二、视觉层级（必须严格控制）

层级结构由上到下：

1. 背景（暗）
2. 地球（主体）
3. 大气光（氛围）
4. 城市点（基础数据）
5. 光柱（核心数据）
6. 流动弧线（动态）
7. UI（信息层）

### 规则

- 同一时间只允许1~2个视觉焦点
- 其他必须"让位"（降低亮度 / 动画）

---

## 三、地球调优（质感来源）

### 1. 自转速度（非常关键）

```javascript
earth.rotation.y += 0.0008;
```

**原则：**
- 慢到"几乎感觉不到"
- 但停止后会觉得"少了点东西"

### 2. 大气光（高级感核心）

**Shader强度建议：**
```glsl
float intensity = pow(0.8 - dot(vNormal, vec3(0,0,1.0)), 3.0);
```

**调优逻辑：**
- 不要太亮
- 只在边缘出现
- 颜色偏蓝青（#00D1FF）

### 3. 地球亮度控制（关键）

```javascript
material.emissiveIntensity = 0.4;
```

**否则：**
- 地球太亮 → 光柱不突出

---

## 四、光柱调优（最重要模块）

### 1. 高度映射（避免"刺眼"）

```javascript
height = Math.log(listeners + 1) * 0.8;
```

**不要线性：**
- 否则大城市直接炸屏

### 2. 呼吸动画（灵魂）

```javascript
scale.y = baseHeight + Math.sin(time * 2) * 0.1;
```

**原则：**
- 幅度小（0.05~0.15）
- 不同步（加随机phase）

### 3. 渐变透明（必须）

**Shader逻辑：**
```glsl
alpha = smoothstep(0.0, 1.0, vY);
```

- 顶部更亮，底部更淡

### 4. 顶部"能量点"（加分项）

- 在光柱顶端加一个小球
- 带Bloom

**效果：**
"数据在发光，而不是一根柱子"

---

## 五、流动弧线调优（高级感来源）

### 1. 曲线高度（非常关键）

```javascript
mid.y += distance * 0.3;
```

**原则：**
- 距离越远 → 弧线越高

### 2. 粒子流速（节奏感）

```
speed = 0.002 ~ 0.01
```

**分类：**
- 近距离：慢（稳定）
- 远距离：快（活跃）

### 3. 尾迹长度

**控制方法：**
- 粒子数量
- 或 shader fade

**推荐效果：**
- 头亮尾淡（像流星）

---

## 六、Bloom（很多人用错）

**推荐参数（直接用）**
```javascript
strength: 1.8
radius: 0.6
threshold: 0.25
```

**调优原则：**

❌ 错误
- 全屏发光（廉价感）

✅ 正确
- 只让：
  - 光柱顶部
  - 粒子
  - 城市点
    发光

---

## 七、交互动效（决定"像不像产品"）

### 1. 相机飞行（必须丝滑）

```javascript
ease: "power3.inOut"
duration: 1.2 ~ 1.8
```

### 2. 点击城市（完整流程）

**必须有：**
1. 光柱放大
2. 相机飞过去
3. UI弹出

**节奏：** 点击 → 0.2s 高亮 → 1.2s 飞行 → UI出现

### 3. Hover反馈（细节）

- 光柱轻微变亮
- 粒子速度增加

**小细节 = 高级感**

---

## 八、音频驱动（让它"活起来"）

**控制维度：**
- 光柱高度（轻微）
- 粒子速度
- Bloom强度

**示例：**
```javascript
beam.scale.y += frequency * 0.002;
```

**注意：**
- 不要剧烈变化
- 否则变成"蹦迪UI"

---

## 九、配色体系（直接用这套）

**主色：**
- 青蓝：#00D1FF
- 紫：#7C3AED

**辅助：**
- 点缀：#00FFA3
- 背景：#050510

**原则：**
- 全局不超过 3 种高亮色

---

## 十、终极细节（拉开差距的地方）

### 1. 动画不同步

```javascript
Math.sin(time + randomOffset)
```

- 避免"机械感"

### 2. 微延迟（高级感关键）

- 不同城市光柱延迟启动
- 弧线延迟出现

### 3. 呼吸节奏统一

- 所有动画共享：`globalTime`
